PiSLA v1.7.1 — حزمة التحديث
============================

المحتويات:
- PiSLA-Desktop-v1.7.1.zip: مشروع Electron لنسخة Windows.
- PiSLA-Android-Project-v1.7.1.zip: مشروع Android مع ملف بناء APK عبر GitHub Actions.
- .github/workflows/build-windows.yml: سير عمل بناء Windows من أرشيف المشروع.

أبرز تعديلات هذه النسخة:
1. إضافة لوحة ألوان للكتابة، وألوان مستقلة لخلفية الترويسة ونصها.
2. التحكم في نوع خط الترويسة وحجمه.
3. أنماط خريطة: متفرعة، جدول، وبطاقات الأصل فوق الفرع مع فاصل.
4. اختيار مصدر الخريطة من «هيكلة الحصة» أو «الجذاذة التفصيلية».
5. اختيار حقول الجذاذة التي تملأ الفروع تلقائياً، بما فيها الأهداف الإجرائية والوسائل وتعليمات الأستاذ وأفعال المتعلم والتقويم.
6. منع تكسير الكلمات داخل خلايا الجداول، مع السماح بالتمرير الأفقي عند الحاجة.
7. توسيع مساحة العمل المكتبية وتحسين التوافق مع الهاتف.
8. الإبقاء على إمكانية تحديد العناصر وحذفها من شريط إجراءات العنصر المحدد.

تحديث Windows على GitHub:
- ارفع PiSLA-Desktop-v1.7.1.zip إلى جذر المستودع.
- ضع ملف سير العمل في .github/workflows/build-windows.yml.
- شغّل Actions ثم Build PiSLA Windows EXE.
- نزّل Artifact باسم PiSLA-Windows-v1.7.1.

تحديث Android على GitHub:
- استخرج PiSLA-Android-Project-v1.7.1.zip.
- ارفع محتويات مجلد PiSLA-Android إلى المستودع المخصص للمشروع، مع الحفاظ على بنية الملفات.
- شغّل سير العمل الموجود في .github/workflows/build-apk.yml.
- نزّل APK من Artifacts.

التحقق:
- تم فحص صياغة JavaScript داخل HTML بواسطة Node.js، وعدم تكرار معرّفات عناصر HTML، وصحة JSON الخاص بحزمة Electron، وصحة AndroidManifest.xml.
- لم يتم في هذه البيئة بناء EXE أو APK فعلياً، ولم يكتمل اختبار تشغيل تفاعلي في Chromium. لذلك يجب اعتبار البناء على GitHub والاختبار على Windows وAndroid خطوة تحقق لازمة قبل الاعتماد النهائي.
